# CPU-Z 说明

## 一、CPU-Z 简介

CPU-Z 是一款基于 CPUID SDK 开发的免费系统信息检测软件，可以详细查看计算机的硬件配置信息。

**主要功能**：
- 查看 CPU 详细信息（型号、频率、缓存、指令集等）
- 查看主板信息（制造商、芯片组、BIOS 等）
- 查看内存信息（类型、大小、频率、时序等）
- 查看显卡信息
- 进行 CPU 基准测试

**官方网站**：https://www.cpuid.com/

## 三、使用方法

### 3.1 安装和运行

1. 下载 CPU-Z 安装包
2. 运行安装程序，按照提示完成安装
3. 启动 CPU-Z

### 3.2 查看 CPU 信息

1. 打开 CPU-Z
2. 默认显示 **处理器** 标签页
3. 查看关键信息：
   - **处理器名称**：CPU 型号
   - **代号**：CPU 架构代号
   - **时钟**：当前核心速度和倍频
   - **缓存**：各级缓存大小
   - **核心数/线程数**：物理核心和逻辑线程数量

### 3.3 查看主板信息

点击 **主板** 标签页，查看：
- 主板制造商和型号
- 芯片组信息
- BIOS 版本和日期

### 3.4 查看内存信息

点击 **内存** 标签页，查看：
- 内存类型（DDR4、DDR5 等）
- 内存大小
- 内存频率
- 时序参数

### 3.5 查看 SPD 信息

**SPD 是什么？**

SPD（Serial Presence Detect）是内存条上的一个小型 EEPROM 芯片，存储了内存条的详细信息。

**主要功能**：
- 存储内存条的型号、制造商、容量等基本信息
- 存储内存的时序参数（如 CAS 延迟、RAS 延迟等）
- 存储内存的速度等级（如 DDR4-3200、LPDDR4-4267）
- 存储内存的电压信息

**工作原理**：
当计算机启动时，主板 BIOS 会读取 SPD 芯片中的信息，自动配置内存控制器，确保内存以最佳参数运行。这个过程称为"内存自动配置"。

**SPD 的重要性**：
- **兼容性**：确保内存条与主板兼容
- **稳定性**：确保内存运行在稳定的参数下
- **性能**：确保内存发挥最佳性能

点击 **SPD** 标签页，查看：
- 内存条详细信息
- 制造商
- 最大速度
- 时序参数

### 3.6 查看显卡信息

点击 **显卡** 标签页，查看：
- 显卡型号
- 核心频率
- 显存大小

### 3.7 基准测试

点击 **基准分** 标签页，进行：
- CPU 单线程基准测试
- CPU 多线程基准测试
- CPU 稳定性测试
