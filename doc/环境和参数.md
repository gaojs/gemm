# 环境和参数配置指南

## 概述

本项目的性能测试和绘图依赖于三个关键参数，这些参数定义在 [proc_parameters.m](file:///home/hill/gemm/proc_parameters.m)（MATLAB 版）和 [PlotAll.py](file:///home/hill/gemm/PlotAll.py)（Python 版）中：

- `nflops_per_cycle`：每时钟周期可执行的浮点运算数
- `nprocessors`：使用的处理器数量
- `GHz_of_processor`：处理器时钟频率（GHz）

这三个参数用于计算理论峰值性能 `max_gflops = nflops_per_cycle * nprocessors * GHz_of_processor`，作为性能图表的 Y 轴上限。

---

## 参数获取方法

### 1. 获取处理器数量 (nprocessors)

```bash
# 物理核心数
grep "cpu cores" /proc/cpuinfo | uniq

# 逻辑核心数
nproc --all
```

本项目的 makefile 中设置了 `OMP_NUM_THREADS=1` 和 `GOTO_NUM_THREADS=1`，即**单线程运行**，因此 `nprocessors = 1`。

---

### 2. 获取处理器时钟频率 (GHz_of_processor)

```bash
# 方法1：从 /proc/cpuinfo 获取基础频率
grep "cpu MHz" /proc/cpuinfo | head -1

# 方法2：查看 CPU 型号，查询技术规格
grep "model name" /proc/cpuinfo | head -1

# 方法3：查看硬件最大频率（包含睿频）
cat /sys/devices/system/cpu/cpu0/cpufreq/cpuinfo_max_freq 2>/dev/null

# 方法4：使用 cpupower（需安装）
sudo apt install linux-tools-common linux-tools-generic
sudo cpupower frequency-info
```

---

### 3. 获取每时钟周期浮点运算数 (nflops_per_cycle)

| 指令集 | 寄存器宽度 | 单寄存器双精度数 | 理论峰值 (mul+add) |
|--------|-----------|-----------------|-------------------|
| SSE | 128 位 | 2 个 double | 4 flops/cycle |
| AVX2 | 256 位 | 4 个 double | 8 flops/cycle |
| AVX512 | 512 位 | 8 个 double | 16 flops/cycle |

## 生成图像的步骤

### 步骤1：运行测试生成数据

```bash
cd /home/hill/gemm
make run
```

### 步骤2：配置绘图参数

编辑 [proc_parameters.m](file:///home/hill/gemm/proc_parameters.m) 或 [PlotAll.py](file:///home/hill/gemm/PlotAll.py)：

```matlab
nflops_per_cycle = 8;
nprocessors = 1;
GHz_of_processor = 4.6;  % 根据实际情况调整
```

### 步骤3：生成图像

```bash
# 使用 Python（推荐）
source /home/hill/gemm/.venv/bin/activate
python PlotAll.py

# 使用 Octave
octave PlotAll.m
```

### 步骤4：查看生成的图像

生成的图像保存在当前目录，命名格式为：`compare_<old_version>_<new_version>.png`
