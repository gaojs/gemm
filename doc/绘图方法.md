## 一、Octave 简介

### 1.1 什么是 Octave

**GNU Octave** 是一种高级解释型编程语言，主要用于数值计算。它提供了线性和非线性问题的数值求解能力，以及丰富的数据可视化和图形处理功能。Octave 通常通过交互式命令行界面使用，也可以编写非交互式脚本程序。

### 1.2 核心功能

| 功能类别 | 具体能力 |
|---------|---------|
| **数值计算** | 线性代数、方程求解、数值积分、微分方程 |
| **矩阵运算** | 矩阵创建、运算、分解、特征值计算 |
| **数据可视化** | 2D/3D 绘图、直方图、误差棒图、等高线图 |
| **编程语言** | 条件语句、循环、函数定义、文件操作 |
| **扩展性** | 通过包系统扩展功能 |

### 1.3 与 MATLAB 的关系

Octave 的语法与 MATLAB 高度兼容，大多数 MATLAB 程序可以轻松移植到 Octave 运行。这使得 Octave 成为 MATLAB 的优秀开源替代方案。

## 三、安装方法

### 3.1 Linux（Ubuntu/Debian）

```bash

sudo apt update

# 安装 Octave
sudo apt install octave

# 安装常用包
sudo apt install octave-signal octave-control
```


## 四、基本使用

### 4.1 启动方式

| 命令 | 说明 |
|------|------|
| `octave-cli` | 命令行模式 |
| `octave --gui` | 图形界面模式 |
| `octave script.m` | 执行脚本文件 |

### 4.2 交互式操作

```octave
# 基本计算
x = 10;
y = 3.1416;
z = x * y;

# 矩阵操作
A = [1 2 3; 4 5 6; 7 8 9];
b = [1; 2; 3];
x = A \ b;  # 求解 Ax = b

# 显示结果
disp(z);
disp(x);
```

### 4.3 脚本文件

创建 `script.m` 文件：

```octave
% 示例脚本
x = -10:0.1:10;
y = sin(x);
plot(x, y);
title('Sine Function');
xlabel('x');
ylabel('sin(x)');
```

执行脚本：

```bash
octave script.m
```

## 五、绘图方法

### 5.1 基本绘图命令

#### 2D 绘图

```octave
% 创建数据
x = linspace(0, 2*pi, 100);  % 生成 0 到 2π 的 100 个等间距点

% 绘制正弦曲线
plot(x, sin(x));
title('Sine Wave');
xlabel('x');
ylabel('sin(x)');
grid on;
```

#### 多曲线叠加

```octave
x = linspace(0, 2*pi, 100);

plot(x, sin(x), 'b-', 'LineWidth', 2);  % 蓝色实线
hold on;
plot(x, cos(x), 'r--');                  % 红色虚线
plot(x, 0.5*sin(2*x), 'g:');             % 绿色点线

title('Trigonometric Functions');
xlabel('x');
legend('sin(x)', 'cos(x)', '0.5*sin(2x)');
grid on;
hold off;
```

### 5.2 图形样式

| 颜色 | 符号 | 线型 | 符号 |
|------|------|------|------|
| 蓝色 | `b` | 实线 | `-` |
| 红色 | `r` | 虚线 | `--` |
| 绿色 | `g` | 点线 | `:` |
| 黑色 | `k` | 点划线 | `-.` |

### 5.3 保存图像

```octave
x = linspace(0, 2*pi, 100);
plot(x, sin(x));
title('Sine Function');

% 保存为不同格式
print('sine.pdf');      % PDF 格式
print('sine.png');      % PNG 格式
print('sine.jpg');      % JPG 格式
print('sine.eps', '-depsc');  % EPS 格式

% 指定分辨率
print('sine_highres.png', '-dpng', '-r300');
```

### 5.4 多子图

```octave
x = linspace(0, 2*pi, 100);

subplot(2, 2, 1);  % 2x2 网格，第 1 个子图
plot(x, sin(x));
title('sin(x)');

subplot(2, 2, 2);  % 第 2 个子图
plot(x, cos(x));
title('cos(x)');

subplot(2, 2, 3);  % 第 3 个子图
plot(x, tan(x));
title('tan(x)');

subplot(2, 2, 4);  % 第 4 个子图
plot(x, exp(x));
title('exp(x)');
```

### 5.5 直方图

```octave
% 生成随机数据
data = randn(1, 1000);

% 绘制直方图
hist(data, 30);
title('Normal Distribution');
xlabel('Value');
ylabel('Frequency');
grid on;
```

### 5.6 误差棒图

```octave
x = 1:4;
y = [20, 35, 30, 27];
error = [2, 3, 4, 1];

errorbar(x, y, error, 'b-o', 'LineWidth', 1.5);
title('Data with Error Bars');
xlabel('Category');
ylabel('Value');
grid on;
```

### 5.7 3D 绘图

#### 3D 曲面图

```octave
[X, Y] = meshgrid(-2:0.1:2, -2:0.1:2);
Z = X.^2 + Y.^2;

surf(X, Y, Z);
title('3D Surface Plot');
xlabel('X');
ylabel('Y');
zlabel('Z');
grid on;
```

#### 等高线图

```octave
[X, Y] = meshgrid(-2:0.1:2, -2:0.1:2);
Z = X.^2 + Y.^2;

contour(X, Y, Z, 20);
title('Contour Plot');
xlabel('X');
ylabel('Y');
grid on;
colorbar;
```

### 5.8 对数坐标图

```octave
x = linspace(0.1, 100, 100);
y = x.^2;

subplot(1, 2, 1);
semilogx(x, y);  % X 轴对数坐标
title('Semilog X');

subplot(1, 2, 2);
semilogy(x, y);  % Y 轴对数坐标
title('Semilog Y');
```

## 七、常见问题

### 7.1 图形无法显示

**问题**：命令行模式下绘图不显示窗口

**解决方案**：
```octave
% 检查图形后端
graphics_toolkit('gnuplot');  % 或 'qt', 'fltk'

% 强制刷新
drawnow;
```

### 7.2 保存图像失败

**问题**：`print` 命令报错

**解决方案**：
```octave
% 确保安装了 gnuplot
% Ubuntu: sudo apt install gnuplot

% 指定输出格式
print('output.png', '-dpng');
```

### 7.3 中文显示乱码

**问题**：图形中的中文显示为方框

**解决方案**：
```octave
% 设置字体
set(gca, 'FontName', 'SimHei');
title('中文标题');
```
