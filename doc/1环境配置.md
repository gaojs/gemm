# 开发环境配置

## 一、环境准备

### 1.1 编译环境
- GCC编译器：支持AVX2和AVX-512指令集
- Make构建工具
- Python 3.x（用于性能分析和绘图）

### 1.2 Python依赖
```bash
pip install matplotlib numpy
```

## 二、Shell快捷命令

将以下命令添加到 `~/.bashrc` 或 `~/.zshrc`：

```bash
# 项目目录快捷跳转
alias hh='cd /home/hill'
alias ge='hh && cd gemm'

# 编译和运行
alias gr='ge && make run'

# Python环境管理
alias ga='ge && . .venv/bin/activate'
alias gd='ga && deactivate'

# 性能分析和绘图
alias gp='ga && python PlotAll.py'

# 文件管理
alias mvi='mv *.png ix4'

# 完整流程：编译运行 + 生成对比图 + 移动图像
alias pp='gr && gp && mvi'
```

### 快捷命令说明

| 命令 | 功能 | 使用场景 |
|------|------|---------|
| `hh` | 跳转到用户主目录 | 快速回到主目录 |
| `ge` | 跳转到项目目录 | 开始工作前 |
| `gr` | 编译并运行测试 | 测试单个版本性能 |
| `ga` | 激活Python虚拟环境 | 使用Python工具前 |
| `gd` | 退出Python虚拟环境 | 完成Python工作后 |
| `gp` | 运行PlotAll.py生成对比图 | 性能分析 |
| `mvi` | 移动PNG图像到ix4目录 | 图像文件整理 |
| `pp` | 完整测试流程 | 一键完成测试和分析 |

## 三、性能测试流程

### 3.1 测试单个版本
```bash
# 修改makefile中的NEW变量
make run
```

### 3.2 批量测试所有版本
```bash
./benchmark_all.sh
```

### 3.3 生成性能对比图

**使用PlotAll.py（推荐）：**
```bash
# 对比两个版本
python PlotAll.py output_old.m output_new.m [output.png]

# 或使用快捷命令
gp  # 需要先复制输出文件
```

**使用generate_plots.py（批量）：**
```bash
python generate_plots.py
```

### 3.4 生成基准版本对比图
```bash
python generate_baseline_comparisons.py
```

## 四、常用工作流程

### 4.1 开发新版本
```bash
# 1. 进入项目目录
ge

# 2. 创建新版本源文件
# vim src/MMult-new-version.c

# 3. 修改makefile
# 设置 NEW = MMult-new-version

# 4. 测试性能
gr

# 5. 与旧版本对比
cp output_MMult-old-version.m output_old.m
cp output_MMult-new-version.m output_new.m
gp
mvi

# 或使用一键命令
pp
```

### 4.2 批量性能分析
```bash
# 1. 测试所有版本
./benchmark_all.sh

# 2. 生成综合对比图
python generate_plots.py

# 3. 生成基准版本对比图
python generate_baseline_comparisons.py
```

## 五、文件组织

### 5.1 目录结构
```
/home/hill/gemm/
├── src/                    # 源代码
│   ├── MMult0.c           # 基线版本
│   ├── MMult4-4x8-avx2.c  # AVX2最佳版本
│   └── MMult4-*.c         # 其他版本
├── ix4/                   # 性能测试结果
│   ├── output_*.m         # 性能数据文件
│   └── *.png              # 性能对比图
├── doc/                   # 文档
│   ├── 性能优化.md        # 性能分析文档
│   └── 开发环境配置.md    # 本文档
├── test/                  # 测试工具和结果
├── makefile               # 编译配置
├── PlotAll.py             # 性能对比工具
├── generate_plots.py      # 批量绘图工具
└── benchmark_all.sh       # 批量测试脚本
```

### 5.2 性能数据文件命名
- 格式：`output_<版本名>.m`
- 示例：`output_MMult4-4x8-avx2.m`

### 5.3 性能对比图命名
- 综合对比：`compare_avx2_versions.png`, `compare_avx512_versions.png`
- 基准对比：`avx2_baseline_vs_*.png`, `avx512_baseline_vs_*.png`
- 版本对比：`compare_<旧版本>_<新版本>.png`

## 六、注意事项

1. **单核心测试**：使用 `taskset -c 0` 确保测试在单核心上运行
2. **频率锁定**：部分CPU需要锁定频率以获得稳定结果
3. **矩阵大小**：测试范围 64×64 到 1280×1280，步长64
4. **性能单位**：GFLOPS（每秒十亿次浮点运算）
